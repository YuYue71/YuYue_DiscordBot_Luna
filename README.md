# YuYue_DiscordBot_Luna
- Luna, 版本不相容, 故障版, 能用但不多, 以停止維護

## 📁 專案結構
```
├── config.json # 設置 token 資料
├── main.py # 主程式入口
├── music.py # 音樂播放模組
├── record.py # 語音頻道進出紀錄模組
├── ffmpeg_mode.py # FFMPEG 路徑管理
├── foundation/
│ ├── Help.py # 指令總覽模組
│ ├── help.json # 指令說明資料
│ └── setup.py # 基礎指模組join,stop..
├── TTS/
│ ├── tts_module.py # 文字轉語音 (TTS)
│ └── voice.mp3 # 預設語音檔
├── PlayAI/
│ ├── AI.py # AI 模型文字發話模組
│ └── AI_profile.json # 長期記憶庫資料儲存位置頻道ID
├── README.md # 基本介紹文件
└── requirements.txt # 外部依賴一覽
```

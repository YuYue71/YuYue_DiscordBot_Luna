# YuYue_DiscordBot_Luna
- 一些由 **幽月 YuYue** 所開發的 DiscordBot 功能開源分享
- 此開源包含一些 DiscordBot 的功能(包含由 **幽月 YuYue** 所開發的LunaBot主程式main.py),希望能夠對各位有幫助

## 📁 專案結構
```
├── config.json # 設置 token 資料
├── main.py # 主程式入口
├── music.py # 音樂播放模組
├── record.py # 語音頻道進出紀錄模組
├── ffmpeg_mode.py # FFMPEG 路徑管理
├── foundation/
│ ├── Help.py # 指令總覽模組
│ ├── help.json # 指令說明資料
│ └── setup.py # 基礎指模組join,stop..
├── TTS/
│ ├── tts_module.py # 文字轉語音 (TTS)
│ └── voice.mp3 # 預設語音檔
├── PlayAI/
│ ├── AI.py # AI 模型文字發話模組
│ └── AI_profile.json # 長期記憶庫資料儲存位置頻道ID
├── README.md # 基本介紹文件
└── requirements.txt # 外部依賴一覽
```
